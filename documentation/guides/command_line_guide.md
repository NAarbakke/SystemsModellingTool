
# Command line guide


### Run program as CLI (command line interface)

if in cmd terminal:

to display files, equivalent to 'ls' on unix-based terminals, use: 'dir'
to clear terminal, equivalent to 'clear' or 'clc' in unix-based terminals, use: 'cls'
to run python file, use, from top-level directory, fex: python -m system_specifications.AS_23_KODIAK.parameter_estimations
to install library, use 'python.exe -m pip install "pandas" --trusted-host=pypi.org'

to activate virtual equivalent, navigate to .venv/Scripts then use 'activate'



if python cannot be found on windows, reinstall it by typing "python" in windows start then execute this
